# Compartir resultados

**Estado: pendiente de definición de producto.** No implementar hasta
que las preguntas de abajo tengan respuesta y este documento se
actualice con las decisiones tomadas.

Potencial de adquisición para Pique: una tarjeta de resultado bien
diseñada, compartida por quien gana un reto, puede funcionar como
marketing viral, no solo como una captura bonita para el propio grupo.
Ejemplo de contenido posible:

```
He ganado este pique 🏆
+420 puntos
🔥 14 días de racha
vs Carmen
```

## Preguntas abiertas

- [ ] ¿Qué información exacta se comparte? ¿Qué es privado y qué no
      (puntos, racha, nombre del rival, nombre del círculo)?
- [ ] ¿Estética de la tarjeta? ¿Coincide con la identidad visual actual
      de la app (violeta/lima) o es un formato propio para redes?
- [ ] ¿Se genera como imagen (para compartir en Instagram/WhatsApp
      Stories) o como enlace con preview (Open Graph)?
- [ ] ¿Se quiere optimizar para viralidad/adquisición (con enlace de
      invitación incrustado) o es solo un recuerdo para el propio grupo?
- [ ] ¿Se comparte solo al ganar un reto, o también otros hitos (racha,
      nivel, primer check-in)?
- [ ] ¿Quién puede generar la tarjeta — solo el ganador, cualquier
      participante?
